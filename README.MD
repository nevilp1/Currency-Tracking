# BCA Currency Rate Scraper

A Node.js Discord bot that scrapes exchange rates directly from BCA and can automatically broadcast USD exchange rates to a configured Discord channel.

## Features

* **Live Scraping:** Fetches data from the official BCA website using Axios and Cheerio.
* **Embed Display:** Clean and professional rate presentation.
* **Broadcast Channel Setup:** Allows each server to set one channel as the exchange rate broadcast channel.
* **Scheduled Broadcast:** Supports daily automatic exchange rate posting based on a configured schedule.
* **Server Cleanup:** Removes server data when the bot is kicked or leaves a Discord server.

## Prerequisites

* Node.js v16+
* Discord Bot Token
* Supabase project and credentials
* **Message Content Intent** must be enabled in the Discord Developer Portal.

## Setup

1. **Install:** `npm install axios cheerio discord.js node-cron @supabase/supabase-js dotenv`
2. **Type:** Ensure `"type": "module"` is in your `package.json`.
3. **Environment:** Create a `.env` file and add your Discord and Supabase credentials.
4. **Run:** `node your-bot-file.js`

## Environment Variables

```env
DISCORD_TOKEN=your_discord_bot_token
SUPABASE_URL=your_supabase_project_url
SUPABASE_KEY=your_supabase_key
```

Adjust the Supabase variable names if your `database.js` uses different names.

## Commands

### Public Commands

* `infokurs`: Fetches and displays current USD rates.
* `help`: Displays the bot help menu.
* `kurshelp`: Alternative command for displaying the bot help menu.

### Admin Commands

These commands require the user to have Discord Administrator permission.

* `setchannel`: Sets the current Discord channel as the automatic broadcast channel.
* `setschedule HH:MM`: Sets the daily broadcast time using 24-hour format.

Example:

```txt
setschedule 10:00
```

The schedule uses the **Asia/Jakarta / WIB** timezone.

## Understanding Rates

* **Buy Rate:** The price the bank pays to buy currency from you.
* **Sell Rate:** The price the bank charges to sell currency to you.

## Database Notes

Discord IDs should be stored as text, not numbers.

Recommended columns:

```sql
server_id text
channel_id text
```

Avoid using numeric types for Discord IDs because Discord snowflake IDs are too large for safe JavaScript number handling.

## Example Table

```sql
create table cb_discord_channel (
    id bigint generated by default as identity primary key,
    server_id text not null unique,
    server_name text,
    channel_id text not null,
    schedule_time time not null default '10:00:00'::time,
    created_at timestamptz default now()
);
```

Because this bot uses one broadcast channel per server, `server_id` should be unique.
